# Source-library policy

The knowledge index is an indexer, not a license to acquire or redistribute books. Only add sources that the project is permitted to store and process: public-domain works, openly licensed research, author/publisher-provided files with permission, or material covered by an applicable license. Record provenance and rights before ingestion.

Recommended metadata per source: stable source ID, title, author, publication date, canonical URL or local path, publisher, license/rights basis, retrieval date, checksum, language, and any attribution or retention conditions. Keep the metadata alongside the source inventory. Do not bypass paywalls, access controls, or robots/terms restrictions. For copyrighted books, prefer lawful purchases/licensed access and check whether storage, indexing, and model processing are permitted.

The initial prototype parses only plain text and Markdown. Do not describe a source as ingested until the ingestion report confirms it. Do not describe the corpus as 15,000 books unless the source inventory and successful ingestion counts support that claim.
